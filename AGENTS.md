# Agent Notes

The rules for changes to this repository are in [CONTRIBUTING.md](CONTRIBUTING.md): compatibility,
plugin context, validation and test layering, administration and runtime compatibility, code shape,
pull requests, installation and update, releases and changelog entries. Read it before any change.
Every rule in it applies to agents too. This file only adds what differs for agents.

- Test-only refactors, compatibility fixes, runtime behavior, and administration UI work go into
  separate PRs unless the user asks otherwise.
- After review feedback, add a follow-up commit. Amend or force-push only when the user explicitly
  asks for it.
